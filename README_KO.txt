My Schedule - 개인 일정관리 PWA (초기 버전)

구성
- index.html: 일정 관리 화면 및 기능
- manifest.webmanifest: 홈 화면 설치 설정
- sw.js: 오프라인 캐시용 서비스 워커
- icons/: 앱 아이콘

현재 포함 기능
- 일정 추가/수정/삭제
- 매일/매주/매월 반복 설정 저장
- 일정 완료 체크
- 브라우저 로컬 저장
- 지원 브라우저에서 음성 입력 및 음성 읽기
- 앱이 화면에 열려 있는 동안의 알림 확인

중요한 제한
- 이 버전은 앱이 닫혀 있거나 iOS가 백그라운드에서 중지한 상태에서 정확한 시간에 알림을 보장하지 않습니다.
- 실제 iOS 웹 푸시는 홈 화면 설치 후 권한 요청, 서비스 워커 push 처리, VAPID 기반 푸시 서버가 추가로 필요합니다.
- 반복 일정은 현재 반복 규칙을 저장하는 초기 버전이며, 다음 반복일 계산/반복 알림은 다음 개발 단계에서 보강합니다.
- 일정은 이 기기의 브라우저 저장소에만 저장됩니다. 사이트 데이터 삭제/기기 변경에 대비한 백업 기능은 아직 없습니다.

배포 방법(다음 단계)
1. GitHub 계정에서 새 Public 저장소를 만듭니다.
2. ZIP을 풀고 파일/폴더를 저장소 최상위에 업로드합니다.
3. 저장소 Settings > Pages > Deploy from a branch > main / root 선택 후 Save.
4. 생성된 https 주소를 아이폰 Safari에서 엽니다.
5. 공유 > 홈 화면에 추가 > 웹 앱으로 열기 > 추가.

아이폰에서 알림을 쓰려면 홈 화면에 추가한 앱을 열고 알림 권한 버튼을 눌러야 합니다.
